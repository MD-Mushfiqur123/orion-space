// 02. MATHEMATICAL RIGOR

Scientific Engine: LLM != Scientific Calculator

Ingestion of 25 years (2001–2025) NASA MERRA-2 daily reanalysis data via NASA POWER API, computed strictly with non-parametric statistics.

METHODOLOGY STACK

Zero Hallucination Pipeline

  • [01]
    Mann-Kendall Rank Correlation ($S$): Evaluates monotonic trends without assuming normal distribution or linear homoscedasticity.
  • [02]
    Theil-Sen Robust Estimator ($\beta$): Median of all pairwise slopes, resilient against extreme outliers and cyclone data anomalies.
  • [03]
    Benjamini-Hochberg FDR: Corrects for testing 442 cell-month series at once, so only robust trends are called significant.
